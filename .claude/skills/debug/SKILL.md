## 分诊

先读相关调用链和现有日志，在已授权范围内自行复现；缺少关键运行时状态时再埋点

## 复现与验证

- 能自行执行的流程就自己跑。浏览器场景使用 `playwright-cli` skill，复用持久化登录态，实际操作并检查页面、请求或日志，不把可自动完成的步骤交给用户
- 只有依赖无法访问的设备、账号权限、真实用户操作，或操作超出授权范围时才请用户协助；说明具体步骤和需要的证据
- 复现方式须覆盖故障条件。浏览器模拟、临时测试页和真实桌面 / 设备场景的证据不可互相替代；未复现时明确说明，不以静态推断声称验证通过

## 采集与定位

- 保留失败现场，提出可证伪的假设，在关键分支、异步两侧记录实际值、请求和会话身份
- 优先复用已有日志能力；需要本 skill 的本地服务器时，先读 [服务器操作](references/server-workflow.md)，按其协议登记、增量读取与注销
- 埋点尽量不改变原流程，控制采集内容和频率；不要采集凭证或无关业务数据，不把异步上报当作完全无影响
- 只能由用户复现时，给出明确操作和采集窗口，等待实际证据；不能把无日志等同于分支未执行，先排除埋点和传输失败
- 修复后用原场景验证。临时埋点保留到验证结束，最后只移除本次添加的内容与资源

## 共享资源边界

每会话使用唯一 source 前缀；只读自己的增量日志，不清空共享文件。复用服务器须核对工作区和日志路径，按会话注册 / 注销，仅在确认无其他会话使用时才终止进程。详细命令按需读取，不为普通调试启动完整服务器
