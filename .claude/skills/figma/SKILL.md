name: figma
description: 根据 Figma 链接或 MCP 数据还原界面，处理设计数据到项目代码的映射。不处理普通 UI 实现
---

- MCP 生成代码作为设计证据，不直接作为项目实现；优先映射已有组件、Token 和资源，避免复制一套近似实现
- 将图层布局转换成内容与容器的约束，不机械照搬坐标和固定尺寸；单张设计稿不能证明其他屏宽或交互状态的行为
- 命名字体样式优先映射项目字重 Token，例如 Medium → `font-medium`、Semibold → `font-semibold`；不机械照抄 510 / 590。明确使用可变轴或已有字体映射时按其约定
- 字体不一致时查实际 Rendered Fonts，不能用 Computed 值证明匹配正确；样式名匹配后仍需对照视觉
- 验收使用对应节点截图，在相同文案、容器尺寸和比例下比较；数据与截图矛盾时先定位差异，不凭猜测调整参数
- 交付标明来源节点、实际验证结果及尚未解决的差异
