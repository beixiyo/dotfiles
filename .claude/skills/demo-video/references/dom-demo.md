# 路线 A：DOM 剧本动画

用真实 DOM 编排一段操作演示：光标移动、点击涟漪、打字机、面板开合、镜头推拉。网页里实时播放，再用 `scripts/record.ts` 录成 GIF

## 架构

| 模块 | 职责 |
|---|---|
| `script.ts` 剧本 | 步骤枚举、每步停留时长（时间线）、光标锚点表、镜头焦点表、章节划分。**唯一来源**，调节奏或加环节只改这里 |
| `timing.ts` 时长 | 动画时长与阅读停留；挂载时注入为 CSS 变量，模板与 keyframes 共用一份数值 |
| `playback.ts` 调度 | 按时间线推进 step；代际计数 + 统一清理 timer，停止后过期循环不能写回状态 |
| `measure.ts` 测量 | 元素在画布中的逻辑矩形、锚点、外接矩形、镜头换算；纯函数 |
| 展示组件 | 只按 `step` 派生画面（`step >= X` 判断阶段），不持有时间 |
| 独立录制页 | `?demo=solo` 只渲染演示，固定宽度，给录制脚本用 |

## 关键技巧

- **固定逻辑画布 + 整体等比缩放**：画面按固定尺寸（如 720×450，16:10 适合整行宽屏）排版，外层用 `transform: scale(容器宽 / 画布宽)` 适配。任意宽度构图一致，不会在窄屏互相压住。文字说明（章节、字幕）放在缩放层外，用真实字号，窄屏仍可读
- **镜头 = 平移 + 缩放**：焦点矩形中心对准视口中心，平移量钳制在画布内（不露空白）：
  `x = clamp(W/2 - cx*z, W - W*z, 0)`，`transform-origin: 0 0`，`transform: translate(x, y) scale(z)`
  焦点可以是多个元素的外接矩形（如"按钮 + 预览卡"一起入镜）
- **测量用 offset 链，不用 getBoundingClientRect**：沿 `offsetParent` 累加 `offsetLeft/offsetTop` 到画布根，得到未变换的逻辑坐标，不受镜头缩放、入场动画、适配缩放影响。按需重测：每步 DOM 变化后（微任务里）、语言切换后、字体加载后
- **光标、涟漪、高亮都放在镜头层内**，推镜时一起放大，像 Screen Studio
- **打字机存字数不存文本**：`typedCount` + `Array.from(text).slice(0, n)`，中途切语言也对得上；按码点切分兼容中文和 emoji
- **叙事要有结果**：只演示"复制成功"不够，要演到用户关心的终点（这次是 AI 改代码后按钮真的变红）
- **章节导航**：演示下方 2–4 个章节 + 进度条，点击跳到章节起点；进度条动画时长取自时间线求和，按轮次 key 重建节点重启动画
- **播放策略**：进入视口且页面可见才播，离开即停回 idle；录制模式（`autoplay`）忽略这些条件

## 已踩的坑

| 坑 | 现象 | 解法 |
|---|---|---|
| Tailwind v4 `scale-*` / `translate-*` 编译为独立 `scale` / `translate` 属性 | `transition-[transform]` 下面板直接跳出，没有过渡 | `transition-[opacity,scale,translate]`；内联 `style.transform` 才配 `transition: transform` |
| 镜头与淡出共用一个 transition 时长 | 淡出没走完下一轮就开始，循环接缝跳变 | 透明度单独用淡出时长，淡出步停留 ≥ 淡出时长；回到 idle 时淡入加延迟，状态复位发生在全透明期间 |
| SolidJS 在 effect 里启动 async 循环 | 循环首段同步读取的信号被 effect 追踪，每推进一步就重启 | `untrack(() => loop())`；React 同理注意依赖数组 |
| SSR 下执行 `onCleanup` / 卸载逻辑 | 预渲染时 `window is not defined` | 清理里用全局 `clearTimeout`，`window.*` 只放在 onMount 内 |
| `prefers-reduced-motion` 时定格静态帧 | 用户认为演示坏了、被降级 | 保持播放；确需照顾时只关大幅位移 |
| 凭印象模拟产品界面 | 标签文案、状态流转、反馈形式和真实产品不一致 | 动手前读真实组件源码/截图，列出要复刻的文案、颜色、状态机 |
| 弹出卡片按"元素右侧"定位 | 靠近画布右缘时溢出被裁 | 位置钳制到画布内：`min(right + gap, W - cardW - margin)` |
| 只在某一步测量一次 | 面板高度随步骤变化，镜头焦点偏移 | 每步变化后都重测（成本很低） |
| 隐藏元素的 ref 仍指向已卸载节点 | 测量到错误坐标 | offset 链走不到画布根时返回 null 并跳过 |
