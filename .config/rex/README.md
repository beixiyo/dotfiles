# Rex

`init.lua` 定义快捷键，修改后执行：

```sh
"$REX_BIN_DIR/rex" config check
"$REX_BIN_DIR/rex" config reload
```

`themes/mocha.ghostty` 在 Settings → Themes → Import 导入；文件变化不会自动同步到已导入主题

## macOS 客户端设置

以下选项保存在 Rex 客户端偏好中，不由 `init.lua` 管理：

- Terminal：Maple Mono NF，12 pt；备用字体 Symbols Nerd Font Mono；方块光标、不闪烁；Option 键发送 Alt；选中即复制
- Interface：Compact pane；关闭未聚焦 pane 与窗口的淡化
- Themes：Mocha
